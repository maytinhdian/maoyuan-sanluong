Xuất file Excel

File đúng mẫu V20, các cột tính vẫn là công thức để kiểm tra lại. File của một ngày chứa mọi số liệu đến hết ngày đó (lũy kế tháng, thiếu hôm trước tính đủ), sheet HIEN_THI hiện ngày đó.

Máy chủ cũng tự xuất mỗi ngày một file vào thư mục XuatExcel (giờ xuất đặt trong app, mặc định 22:00).
